- 判断：属于「站点没有任何稳定标识」的情形。无 id / data-* / 语义类名，唯一结构特征是
  `fixed + pointer-events-none + z-50` 这组穿透式浮层写法 —— 但同一套写法页面上不止一处
  （悬浮提示也是），所以**不能**无 keywords 直接进 CSS 层。
- 规则改法：

  - keywords 只取品牌名：按钮文案已从「询问 ChatGPT / 分享所选内容」改成「向 ChatGPT 提问」，
    以后还会改，只有品牌名不变。
- 测试：ChatGPT 分块换新夹具，新增 `tooltip`（同工具类、不含品牌名 → 必须保持可见）与
  `barReworded`（文案改成 Ask ChatGPT 仍须命中）两个用例，全套 38 项全绿。
  反向验证：去掉 keywords → 4 项失败，其中一条正是「悬浮提示被误伤」，证明守卫不是装饰。
