# 2026-09-25

## 修复 ChatGPT 选区菜单失效（hide-ai-selection-menu.js v2.0 → 2.1）

- **根因**：ChatGPT 改版后选区浮层菜单项由「询问 ChatGPT / 开始写作 / 分享所选内容」变成只剩前两项；
  规则里 `keywords.every()` 要求全包含「开始写作」，判定永远失败 → 菜单不再被隐藏。
  原选择器 `div.shadow-long.flex.overflow-hidden.rounded-xl` 本身仍能命中，问题纯在 keywords。
- **修复**：
  1. 新增高精度选择器 `[class*="selectionPopover"]`（外层类名形如 `<hash>_selectionPopover`，哈希会变、语义后缀稳定）。
  2. 兜底 keywords 只保留最稳定的一项 `询问 ChatGPT`。
  3. 新增 CSS 层：不带 keywords 的高精度选择器在 `document-start` 直接写 `<style>` 隐藏，
     同时解决"首帧闪现"与"页面重写浮层行内 style 冲掉 display:none"两类问题。
  4. observer 增加 `attributes: ['class','style']`；新增 250ms（前 30s）→ 3s 兜底轮询；
     幂等判定由 `style.display === 'none'` 改为 `getPropertyPriority('display') === 'important'`。
- **新增** `test/userscript.test.js`：最小 DOM 桩回归测试，12 项断言，`node test/userscript.test.js`。
  已做反向验证（临时把旧关键词塞回去）确认测试确实会报出该失效，不是假绿灯。
- 相关：顺手修正了技能 `webpage-adblock-userscript` 的 dom-stub 桩缺陷（见下）。
